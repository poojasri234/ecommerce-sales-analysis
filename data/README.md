# Data instructions

This repository does **not** include the raw transaction workbook. The project uses the public UCI Online Retail dataset under the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/).

1. Open the [UCI Online Retail dataset page](https://doi.org/10.24432/C5BW33).
2. Download the dataset archive and extract `Online Retail.xlsx`.
3. Save the workbook in this directory with the exact path:

   ```text
   data/Online Retail.xlsx
   ```

4. Run the command in the repository README.

The workbook is ignored by Git so the repository contains only analysis code and aggregate outputs. The source represents transactions for a UK-based non-store online retailer from December 2010 to December 2011; currency values are reported in GBP (£).
